# 🎙️  Voice AI Agent

A Python-based Voice AI Assistant that converts spoken questions into text, processes them using rule-based response logic, and generates spoken replies. Built with Faster Whisper, gTTS, and Gradio, the project demonstrates an end-to-end voice interaction pipeline using Google Colab.

## 📌 Project Overview

The Team 4 Voice AI Agent demonstrates how speech recognition, Python-based response processing, and text-to-speech technologies can be combined to create an interactive voice assistant.

Users can record a question through a microphone, view the recognized text, receive a response, and listen to the generated audio.

## 🎯 Project Objectives

- Demonstrate speech-to-text conversion.
- Process user questions using Python.
- Generate spoken responses from text.
- Build an interactive web interface for voice interaction.
- Measure the time taken to process a question and generate the response audio.

## ⚙️ How It Works

The application follows five main stages:

1. **Voice input:** The user records a question through the microphone.
2. **Speech recognition:** Faster Whisper converts the recording into text.
3. **Response processing:** Python applies predefined rules to select an appropriate answer.
4. **Text-to-speech:** gTTS converts the answer into spoken audio.
5. **Audio output:** The user can play the assistant's response through the Gradio interface.

## 🚀 Getting Started

### Prerequisites

- A Google account.
- Access to Google Colab.
- A microphone or an audio recording.
- An internet connection for package installation and gTTS.

### Installation and Execution

1. Open the project notebook in Google Colab.
2. Run the dependency installation cell.
3. Run the cell that imports the libraries and loads the Faster Whisper model.
4. Run the application cell.
5. Allow the application to launch.
6. Open the Gradio link generated by Colab.
7. Record a question, submit it, and listen to the response.

**Important:** Keep the Colab runtime running while using the shared Gradio link.

## ⏱️ Processing-Time Measurement

The application measures the time from the start of processing after submission until the response audio file has been generated.

This measurement includes speech recognition, response selection, and text-to-speech generation. It does not include the time spent recording the question or listening to the response.

Example-button timing excludes speech recognition because the example question is already text.

## ⚠️ Current Limitations

- Responses are selected using predefined Python rules.
- The assistant cannot reliably answer every possible question.
- It does not use a large language model to generate unrestricted answers.
- Internet access is required for gTTS and may be needed for other services or dependencies.
- The public demonstration link depends on the Colab runtime remaining active.
